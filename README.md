# Ceylon K9 Academy — Luxury Digital Platform
> **"Smart Training For Happy Dogs"**  
> Sri Lanka's premier canine education institution and professional dog training academy.

---

## 🌟 Tech Stack
- **Backend:** Node.js + Express.js
- **Template Engine:** EJS (Structured modular partials & views)
- **Styling:** Tailwind CSS + Custom Master Styles (`public/css/style.css`)
- **Animations & Motion:** GSAP + ScrollTrigger + Web Audio API Haptic Synthesizer
- **Icons:** Lucide Icons
- **Data Architecture:** Fully structured local datastore (`data/data.js`)
- **Assets:** Official high-res banners & certified graduate albums from the workspace

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start the Server
```bash
npm start
```
or run in live development mode:
```bash
npm run dev
```

### 3. Open in Browser
Visit [http://localhost:3000](http://localhost:3000)

## 🧭 Page Routes & Features

| Route | Purpose & Features |
|---|---|
| `/` | Master Homepage with Hero banner, Metrics (130K+ followers, 2.5K+ graduates), Interactive AI Dog Assessment Quiz, Featured Programs, Certified Graduates, 4-Step Methodology, Tactical Equipment showcase, Testimonials, FAQ Accordion, and Luxury VIP CTA. |
| `/programs` | Full academic curriculum catalog, filter tags, tuition pricing (LKR), key behavioral milestones, and interactive comparison matrix. |
| `/programs/:slug` | Dedicated syllabus and deep dive for each training program (e.g. `/programs/master-obedience`, `/programs/puppy-foundation`). |
| `/gallery` | Hall of Champions & Certified Graduates with filterable tabs (Rottweilers, German Shepherds, Boxers, Puppies) and interactive image zoom lightbox. |
| `/equipment` | Professional tactical gear and products store with one-click direct WhatsApp ordering. |
| `/about` | Ethology science, Master Trainer philosophy, and mission. |
| `/contact` | Instant booking evaluation form and WhatsApp concierge routing. |
| `/api/book` | REST API handling booking inquiries with auto-generated prefilled WhatsApp confirmation links. |
| `/api/assessment` | Interactive behavioral quiz evaluation algorithm. |
